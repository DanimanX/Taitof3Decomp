# Darius Gaiden (Taito F3) Kernel Analysis (`0x1A00`–`0x2400`)

Source analyzed: `work/disasm/kernel_1A00_2400.s` (generated by scripts/ghidra/export_disasm.py) (`A5 = 0x408000`, loaded at `001DBC` from `00235C`).

> **Hypothesis check (16 vs 32 slots):** **CONFIRMED** cooperative/VBlank-preemptive multitasking kernel with TRAP syscalls, **but with 16 actual task slots (`0..15`), not 32.** While `task_active_mask` (`A5-0x1904`) is 32-bit, `FUN_00002274` loops `0..31` (`00227C`), and `TRAP_11` masks `& 0x1F` (`0021CA`), all per-task RAM arrays (`-0x1948`, `-0x18F8`, `-0x18B8`, `-0x1878`) hold only **16 entries**, the ROM stack table (`002368`–`0023A8`) provides 16 × 1 KB stacks (`0x4062B4` down to `0x4022B4`), `TRAP_1` only allocates slots `0..15` (`001E90`/`001E9A`), and `TRAP_6/8/9/10` reject IDs `> 15`.

## 2. TRAP Syscalls & Functions

> **JSR-callable TRAP stubs (CONFIRMED):** Every `TRAP_1`..`TRAP_12` is immediately preceded by an identical 22-byte prologue (disassembled only at `FUN_00001f62` and `LAB_00002200`; raw bytes `40 ED EB A8 00 7C 07 00 2F 57 FF FE 42 6F 00 02 55 8F 3F 2D EB A8` at `001DF8`, `001E32`, `001E60`, `001F1A`, `001F62`, `001F96`, `001FD2`, `002046`, `0020B2`, `002140`, `0021A8`, `0021F8`). It saves SR to `A5-0x1458`, masks IRQs, and rewrites a JSR return frame `[PC.l]` into a 68020 Format-0 exception frame `[SR.w][PC.l][0x0000.w]` before falling into the TRAP body.

### Kernel TRAP Syscalls (arguments passed on caller's stack above exception frame)

- **`TRAP_1` (`001E76`, stub `001E60`) — Spawn task [CONFIRMED]:** Inputs: stack `arg0.l`=entry PC (`001EEE`), `arg1.l`=slot request (`0`: lowest free `0..15`; `1..15`: exact slot; `>=16`: highest free `15..0`, `001E84`–`001EAC`), `arg2.l`=task parameter (`001EE2`). Output: `D0`=allocated task ID (or `0` on failure, `001E96`/`001EAA`/`001EB4`). Side effects: sets bit in `task_active_mask` (`001EB8`), sets `task_mbox_empty[id]=0xFFFF` (`001EC6`), sets `task_status[id]=parent_id<<16` (`001ECE`–`001ED6`), builds initial stack frame with return address `0x1E48` (`TRAP_3`, `001EE6`), `SR=0x2000` (`001EF2`), caller's `D1..A6` + `D0=id` (`001EF6`–`001F08`), stores SP in `task_saved_sp[id]` (`001F10`).
- **`TRAP_2` (`001E0E`, stub `001DF8`) — Kill tasks by bitmask [CONFIRMED]:** Input: `arg0.l`=kill mask (`001E16`). Output: none (regs preserved). Side effects: clears bits `arg0 & ~(1<<cur_id) & ~1` in `task_active_mask` (`001E1E`–`001E28`), protecting self and task 0.
- **`TRAP_3` (`001E48`, stub `001E32`) — Exit current task [CONFIRMED]:** Inputs/Outputs: none (does not return). Side effects: hangs forever if `cur_task_id==0` (`001E50`–`001E54`); otherwise clears self bit in `task_active_mask` (`001E56`–`001E58`) and jumps to scheduler (`001E5C`). Also pushed as default return PC by `TRAP_1` (`001EE6`).
- **`TRAP_4` (`001F30`, stub `001F1A`) — Sleep N frames (interruptible) [CONFIRMED]:** Input: `arg0.l` low word=frame count (`001F4A`). Output on resume: `D0`=`0` on timeout, or wakeup value if woken early by `TRAP_11` (`0022D4`). Side effects: saves context (`001F34`–`001F3C`), sets `task_status[cur]=(0xA000|cur_id)<<16 | count` (bits 31+29, `001F44`–`001F52`), clears `task_wakeup_val[cur]` (`001F5A`), yields to scheduler (`001F5E`).
- **`TRAP_5` (`001F78`, stub `FUN_00001f62`) — Yield until next frame [CONFIRMED]:** Inputs/Outputs: none (all regs preserved). Side effects: saves context (`001F7C`–`001F84`), clears bits 31..30 of `task_status[cur]` (`001F8C`), yields to scheduler (`001F92`).
- **`TRAP_6` (`001FE8`, stub `001FD2`) — Receive message from sender (blocking) [CONFIRMED]:** Input: `arg0.l & 0xF`=sender ID (`002012`–`002016`). Output: `D0`=32-bit message (`00203C` or via `0022D4`; no-op if `cur>15`, `001FFE`). Side effects: tests & sets bit `sender` in `task_mbox_empty[cur]` (`00201A`); if already pending (`0`), pops message from `task_mailbox[16*cur+4*sender]` into saved `D0`, writes `sender` to `task_status[cur]` bits 23..16 (`002032`), returns immediately; if empty (`1`), saves context, sets `task_status[cur]=(0x6000|cur_id)<<16 | (1<<sender)` (bits 30+29, `00201E`–`002028`), yields (`00202A`).
- **`TRAP_7` (`001FAC`, stub `001F96`) — Wait for signal mask [CONFIRMED]:** Input: `arg0.l` low word=16-bit sender wait mask (`0` = wait indefinitely until `TRAP_11`, `001FC0`). Output: none (all regs preserved). Side effects: saves context (`001FB0`–`001FB8`), sets `task_status[cur]=(0x4000|cur_id)<<16 | mask` (bit 30, `001FBA`–`001FCC`), yields (`001FCE`).
- **`TRAP_8` (`00205C`, stub `002046`) — Block target tasks on caller [CONFIRMED]:** Input: `arg0.l`=target task bitmask (`002070`; self bit cleared `002074`; no-op if `cur>15`). Output: none. Side effects: for each target `t`, sets bit 30 and bit `cur_id` in `task_status[t]` (if bit 30 was 0, clears all except bit 29 first, `002090`–`00209E`), and sets bit `cur_id` in `task_mbox_empty[t]` (`0020A0`–`0020A4`).
- **`TRAP_9` (`0020C8`, stub `0020B2`) — Send message to target task [CONFIRMED]:** Inputs: `arg0.l`=target ID (`0..15`, `0020DC`), `arg1.l`=32-bit message (`00210E`/`002134`). Output: none (no-op if `cur>15` or `target>15`). Side effects: if target has bit 30 set and bit `cur` set in wait mask (`0020F6`–`0020FE`), clears bit `cur`, marks `task_mbox_empty[target]` bit `cur`=1 (`00211C`), and if wait mask reaches 0, clears bit 30 (keeping bit 29), writes `cur` into bits 23..16, and writes `arg1` to `task_wakeup_val[target]` (`002100`–`002114`). Otherwise marks `task_mbox_empty[target]` bit `cur`=0 and buffers `arg1` at `task_mailbox[16*target+4*cur]` (`002124`–`002134`).
- **`TRAP_10` (`002156`, stub `002140`) — Signal/unblock tasks by bitmask [CONFIRMED]:** Input: `arg0.l`=target mask (`00216A`; self cleared `00216E`; no-op if `cur>15`). Output: none. Side effects: for each target with bit 30 & wait-bit `cur` set, clears wait-bit `cur` (`00217C`–`002186`); if wait mask hits 0, zeroes `task_wakeup_val[t]` if bit 29 was set (`00218C`–`002192`) and sets `task_status[t]=cur<<16` (clearing bits 31..29, `002196`–`00219C`).
- **`TRAP_11` (`0021BE`, stub `0021A8`) — Force-wake task with value [CONFIRMED]:** Inputs: `arg0.l & 0x1F`=target ID (`0021C6`–`0021CA`), `arg1.l`=32-bit wakeup value (`0021EC`). Output: none. Side effects: clears bits 31, 30, and low word of `task_status[target]` (preserving bit 29), writes `cur_id` into bits 23..16 (`0021D4`–`0021E8`), stores `arg1` into `task_wakeup_val[target]` (`0021EC`).
- **`TRAP_12` (`00220E`, stub `0021F8`/`002200`) — Flush own mailbox flags [CONFIRMED]:** Input: `arg0.l` low word=sender bitmask (`00221A`). Output: none. Side effects: `task_mbox_empty[cur] |= arg0.w` (`002224`), discarding buffered messages from those senders.

## 4. IRQ2/IRQ3 Handshake & Context Switching

### IRQ2 / IRQ3 Handshake (**CONFIRMED**)
1. **`IRQ2_VBlank` (`001A34`, IPL 2)** fires at VBlank start: sets `irq2_waiting_flag = 0xFF` (`A5-0x5D4E`), clears `irq3_ack_flag = 0x00` (`A5-0x5D4D`), and spins up to `0x401` (1025) iterations of `tst.b (-0x5D4D,A5); dbne D0w` (`001A40`–`001A48`). Because IPL is 2, higher-priority IRQ3 can preempt the spinloop.
2. **`IRQ3_VideoSync` (`001A54`, IPL 3)** fires ~10,000 cycles later: sees `irq2_waiting_flag != 0` (`001A54`), sets `irq3_ack_flag = 0xFF` (`001A5C`), clears `irq2_waiting_flag = 0x00` (`001A60`), and `rte`s back into IRQ2's spinloop.
3. **`IRQ2_VBlank` exits the spinloop immediately**, restores `D0`, and jumps via `001A66` to `FUN_0000222e` — synchronizing the kernel tick to IRQ3 while firing only once per frame.
4. **Fallbacks:** If IRQ3 fires without IRQ2 waiting (`irq2_waiting_flag == 0`), IRQ3 itself jumps to `001A66`→`00222E` (`001A58`). If IRQ3 never arrives within `0x401` loops, IRQ2 times out and still runs `00222E` (leaving `irq2_waiting_flag = 0xFF` so a late IRQ3 only clears it and `rte`s).

### Context Save, Preemption/Overrun Handling & Resume (**CONFIRMED**)
- **What is saved and where:** On every context switch (`TRAP_4/5/6/7` or `FUN_0000222e`), hardware (or the 22-byte JSR stub) pushes an 8-byte 68020 Format-0 frame `[SR.w][PC.l][fmt/vec.w]` onto the running context's stack. The handler masks IRQs (`ori #0x700,SR`), executes `movem.l {A6..D0},-(SP)` (60 bytes, so `D0` is at `(SP)`), and stores the resulting `SP` into `*(cur_saved_sp_ptr)` (`&task_saved_sp[cur]` or `&idle_saved_sp`).
- **Normal VBlank (CPU was in idle, `in_idle_flag == 0xFF`, `002262`–`002272`):** `FUN_0000222e` saves the idle context to `idle_saved_sp`, copies `0xFF` → `was_idle_at_irq`, clears `in_idle_flag`, runs `FUN_00001a0e` on the idle stack, and starts scheduling from task `0` (`002270`→`002284`). When all tasks (`0..31`) finish (`00227C`→`0022DE`), `was_idle_at_irq != 0` (`0022E4`), so `LAB_000022fc` sets `in_idle_flag = 0xFF`, points `cur_saved_sp_ptr` to `idle_saved_sp`, restores idle's `SP`, pops `{D0..A6}`, and `rte`s back into `LAB_00002320`.
- **Frame Overrun / Preemption (CPU was still in a task, `in_idle_flag == 0x00`, `002244`–`002260`):** `FUN_0000222e` saves the preempted task's context to `task_saved_sp[cur]`, copies `0x00` → `was_idle_at_irq`, clears bits 31..30 of `task_status[cur]` (`00224A`), switches `SP` to `kernel_tmp_sp` (`A5-0x1B4C`, `002250`) to run `FUN_00001a0e` safely, and resumes scanning at `cur_task_id` (`00225E`→`002284`, re-entering the preempted task). When the delayed pass later hits slot 32 (`0022DE`), `was_idle_at_irq == 0` forces `LAB_000022ea` to set `was_idle_at_irq = 0xFF`, switch to `kernel_tmp_sp`, and immediately begin the next frame at task `0` without idling.
- **Task Resume (`LAB_000022ba`, `0022BA`–`0022DC`):** Sets `cur_saved_sp_ptr = &task_saved_sp[id]` (`0022C2`), loads `SP = task_saved_sp[id]` (`0022C6`), if bit 29 of `task_status[id]` is set clears it and patches `task_wakeup_val[id]` into `(SP)` (saved `D0`, `0022C8`–`0022D4`), executes `movem.l (SP)+,{D0..A6}` (`0022D8`), and `rte` (`0022DC`) restores the task's `SR` and `PC`.
